マルチに参加する手順

Minecraft Java版 26.3 ＋ MOD のサーバーです。最初に1回だけ設定すれば、あとは起動するだけでMODが自動で最新になります。

全体の流れ（15分ほど）
  1. 主催者にマイクラのユーザー名を伝える
  2. Prism Launcher を入れる
  3. 26.3 ＋ NeoForge のインスタンスを作る
  4. 自動更新の仕組みを入れる
  5. 起動してサーバーに入る

1主催者にユーザー名を伝える

このサーバーは登録した人だけが入れます。Minecraft Java版のユーザー名（ゲーム内の名前）を主催者に送ってください。登録が終わったら、サーバーのアドレスを教えてもらえます。

Minecraft Java版を持っていることが必要です（統合版・スマホ版では入れません）。

2Prism Launcher を入れる

  1. prismlauncher.org から、自分のPC（Windows / Mac）用をダウンロードして入れる。
  2. 起動したら、右上の「アカウント」から Microsoft アカウントでログインする（いつもマイクラで使っているもの）。

いつもの公式ランチャーはそのまま使えます。Prism Launcher は別に入るので、今のワールドには影響しません。

3インスタンスを作る

  1. 左上の「インスタンスを追加」を押す。
  2. バージョンの一覧から 26.3 を選ぶ。
  3. 下の「Mod ローダー」で NeoForge を選び、26.3.0.101 を選ぶ。
  4. 名前は自由（例: マルチ26.3）。「OK」で作る。

4自動更新の仕組みを入れる

  1. このページから packwiz-installer-bootstrap.jar をダウンロードする。
  2. Prism Launcher で、作ったインスタンスを右クリック →「フォルダーを開く」。
  3. 開いたフォルダの中の minecraft フォルダ（見当たらなければ .minecraft）に、ダウンロードした jar を入れる。
  4. インスタンスを右クリック →「編集」→ 左の「設定」→ 上の「カスタムコマンド」タブを開く。
  5. 「カスタムコマンド」にチェックを入れ、起動前コマンドの欄に、次の1行をそのまま貼る。
"$INST_JAVA" -jar packwiz-installer-bootstrap.jar https://nayanaoki.github.io/mc-multi-pack/pack.toml

この1行で、起動するたびに主催者が配っているMODと同じものがそろいます。

5起動してサーバーに入る

  1. インスタンスをダブルクリックして起動する。最初だけ、MODをダウンロードする小さな画面が出ます（17個）。
  2. ゲームは日本語で起動します。英語のままのときは、タイトル画面の地球のボタン（言語）から「日本語」を選んでください（手順4より前に一度起動していた場合など）。
  3. タイトル画面で「マルチプレイ」→「サーバーを追加」→ 主催者から聞いたアドレスを入れて接続する。
メモリが足りずに落ちるときは、インスタンスの「編集」→「設定」→「Java」で、最大メモリを 4096MB くらいにしてください。

62回目から

Prism Launcher でインスタンスを起動するだけです。主催者がMODを更新していれば、起動のときに自動で入れ替わります。自分で何かを入れ直す必要はありません。

うまくいかないとき

  • 「MODが合わない」と言われて入れない: 一度ゲームを閉じて、もう一度起動してください（起動のときに最新になります）。
  • ホワイトリストに入っていないと出る: ユーザー名がまだ登録されていません。主催者に連絡してください。
  • 起動前コマンドでエラーが出る: jar を置いた場所（手順4の3）と、貼った1行に抜けがないかを確かめてください。
  • 26.3 や NeoForge が一覧に出ない: Prism Launcher を最新版に更新してください。
